# M9 idle RSS of `tenko serve --roles controller`: `main` against WP3.5c, 2026-10-15 (Windows)

Measurement M9 (OPS-15, idle resident set below 100 MB) run with the same script on two builds at the same time, as for WP3.5a and WP3.5b ([2026-10-14-m9-idle-rss.md](2026-10-14-m9-idle-rss.md)). The slice 3 rule: no merge may raise the idle RSS by more than 3 MiB without the lead's consent.

## WP3.5c: `main` `043382a` against `wp35c` `930b48b`

WP3.5c adds traces over OTLP (`[telemetry] otlp_endpoint`, the span catalogue of `docs/observability.md` section 8). The configuration of the script sets no endpoint, so traces are off: no tracer provider, exporter, thread or task is built, and the spans in the code are disabled callsites. The difference is what the package costs at rest with telemetry off; the server log of the branch has no telemetry line.

### Summary

Memory figures are MiB. Idle: 21 samples over 600 s after the data creation.

WP3.5c does not raise the idle working set: the branch idles 0.48 MiB below `main`, within the run-to-run noise of a pair (private bytes move by up to 3 MiB between runs of the same binary, see the WP3.5a pairs). Expected: with telemetry off nothing of the package runs.

### Where the difference comes from

Nothing is allocated at rest: without an endpoint `telemetry::layer` returns before it builds anything, and the subscriber has the same layers as on `main`. The release binary grows by 2,490,368 bytes (the OpenTelemetry API, SDK, OTLP exporter and `tracing-opentelemetry`, the TLS of tonic, the span callsites); code that is not executed does not enter the working set. The route table keeps the route and class label of every row for the request span (a few KiB).

### Method

`bench/phase1-server/m9-idle-rss.ps1` as committed: the defaults (200 prefixes, 600 s idle, a sample every 30 s, the platform key provider), the two runs at the same time on ports 18443 (`main`) and 18445 (`wp35c`), started at 12:50:00 local time (+02:00) with nothing else running.

```
pwsh -NoProfile -File bench\phase1-server\m9-idle-rss.ps1 -Binary F:\wp35c-m9\m9-main-server.exe -Port 18443 -WorkDir %TEMP%\tenko-m9-wp35c-main -OutDir bench\phase1-server\results\raw\wp35c-main
pwsh -NoProfile -File bench\phase1-server\m9-idle-rss.ps1 -Binary F:\wp35c-m9\m9-branch-server.exe -Port 18445 -WorkDir %TEMP%\tenko-m9-wp35c-branch -OutDir bench\phase1-server\results\raw\wp35c-branch
```
