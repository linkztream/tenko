- **The re-seeded state file is compact.** At rest after a clean shutdown the re-seeded learner's file is 220.7 MiB at 1,000,000 records (1.26x all tables, 1.54x user table) and 304.0 MiB at 1,500,000 (1.24x and 1.42x), against 2.05x and 2.74x before WP1.1b. An offline `compact()` of these files finds nothing left to remove (220.7 to 220.7 MiB, 304.0 to 304.0 MiB). The in-place re-seed of the leader produces the same files: 514.0 to 220.6 MiB in 4.0 s and 1028.0 to 304.0 MiB in 4.4 s, with writes waiting for that time.
- **The journal stays within its byte limit.** 49 and 51 change sets hold 31 MiB (limit 32 MiB) where the count-only retention kept 177 and 269 change sets of 107.1 and 160.6 MiB. Raw data over all tables is 174.5 MiB at 1,000,000 records (250.2 MiB before) and 246.1 MiB at 1,500,000 (375.2 MiB before); the user table is unchanged.
- **The running file length still carries redb's growth slack.** Right after its re-seed the 1,000,000-record learner's file measured 441.2 MiB (2.53x all tables, so M6 fails on the running figure), twice the 220.7 MiB it has at rest: the compacted file holds no free pages, so the first commit after the install that needed pages doubled it, and redb trimmed it again when it closed. The 1,500,000-record learner had not grown when it was measured (1.24x). Below 4 GiB redb grows a file by doubling, so while the store runs the file can hold up to as much free space again as it has pages in use. The re-seed rule in the store's documentation is therefore stated on the size at start-up (`DiskUsage::state_ratio_at_open`, about 2.0) or, on the running figure, at about 4.0; the incrementally written leaders ran at 2.95x and 4.18x before their re-seed.
- **Installs take longer by the compaction.** M1 shows no empty read in any round and the lookup p99 within 1.22x of the baseline. Compacting the new file took 1.8 to 2.6 s of a 4.6 s median install window at 1,000,000 records (5.7 s before) and 2.7 to 5.4 s of a 34.8 s median window at 6,000,000 records (27.2 s before); the index rebuild varied between 5.4 and 10.4 s on the shared machine.
